# 🛠️ Item Admin — เว็บจัดการ Market list (local)

เว็บ local จัดการรายการ `sv_market` (ของที่ซื้อ/ขายในระบบเศรษฐกิจ Unturned) — ต่อ MySQL ตรง

## รัน
```bash
cd item-admin
npm install
npm start
```
เปิด **http://localhost:3777**

## ใช้งาน
1. เข้าหน้าเว็บ → กรอก **Database connection** (Host, Port, Database, User, Table prefix, **Password**)
   - ทุกช่อง **ถูกจำไว้ (localStorage)** ยกเว้น **Password** ที่ต้องกรอกใหม่ทุกครั้ง
2. กด **เชื่อมต่อ** → เห็นรายการทั้งหมด
3. **เพิ่ม/แก้ไข**: กรอกฟอร์มด้านบน (Item ID, ชื่อ, ราคา, สต็อก, รูป URL, เปิดใช้งาน) → บันทึก
   - แก้ไข: กดปุ่ม "แก้ไข" ที่แถว → ฟอร์มเด้งค่าเดิม
4. **ลบ**: ปุ่ม "ลบ" ที่แถว

## ความปลอดภัย
- เซิร์ฟเวอร์ผูกกับ **127.0.0.1 เท่านั้น** (เข้าได้จากเครื่องนี้)
- **รหัสผ่านไม่ถูกบันทึกลงดิสก์** — อยู่ใน RAM ของเซิร์ฟเวอร์ระหว่างรัน หายเมื่อปิดเซิร์ฟเวอร์
- connection (host/port/db/user/prefix) เก็บใน localStorage ของเบราว์เซอร์เพื่อ prefill เท่านั้น

## หมายเหตุ
- ต่อ MySQL ตัวเดียวกับเซิร์ฟเกม/บอท (เช่น localhost ถ้ารันบนเครื่องเดียวกับ DB)
- ตาราง `sv_market` จะถูกสร้างให้ถ้ายังไม่มี
- แก้ในเว็บแล้ว ในเกมพิมพ์ `/sellreload` ให้มีผลทันที
